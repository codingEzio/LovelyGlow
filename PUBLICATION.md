# Source provenance and verification

This repository is a fresh source-only import selected from the private development project. Its first commit initializes the README, and its second commit imports the reviewed source; neither reproduces the private development history. Private settings, signing configuration, operational records and the original private icon are excluded. The public icon and its attribution are described in [ARTWORK.md](ARTWORK.md).

Build and test commands are in [README.md](README.md). Source compilation and automated tests do not establish signed packaging, installation, Accessibility permission, live overlay behavior or physical display acceptance. Those require separate verification.

The optional font is fetched from its pinned public release; see [DEPENDENCIES.md](DEPENDENCIES.md) and its component notices for provenance and license scope. The source repository does not include the font binary.
